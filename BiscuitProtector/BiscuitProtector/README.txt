🍪 BISCUIT PROTECTOR 2.0 - Ultimate Dipping Simulator
========================================================================

Because every biscuit deserves a safe dip.

HOW TO RUN:
Open `index.html` in any web browser (Chrome, Firefox, Edge, Safari). No build step, node server, or npm packages required!

NEW FEATURES IN v2.0:
- Interactive HTML5 Canvas Dipping Simulator with rising steam, liquid surface waves, and dipping animation.
- Real-time Soggy Absorption Gradient & Crumble Physics when biscuits overdip.
- Synthesized Web Audio Engine for tension ticking audio, dunking splashes, victory chimes, and collapse plops.
- 10+ Biscuit Types (Parle-G, Marie Gold, Good Day, Hide & Seek, Oreo, Bourbon, Digestive, Rusk, Biscoff, and Custom target duration).
- Beverage Selectors (Cutting Chai, Filter Coffee, Green Tea, Warm Milk, Hot Chocolate with unique soak multipliers).
- Game Modes: Classic Dip (Precision), Endurance Challenge (Survival streak), and Zen Practice.
- Career Statistics & Unlockable Achievements (saved automatically in LocalStorage).
- Full Keyboard Control (Spacebar for Start/Save, R for Reset, M for Mute, 1-3 for Tabs).
